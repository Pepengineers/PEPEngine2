# Правила для агентов

## Коммиты

- По умолчанию после завершения задачи и необходимых проверок создавай локальный коммит своих правок без дополнительного запроса подтверждения, если пользователь не попросил оставить изменения без коммита.
- Перед коммитом проверь diff и включи только изменения своей задачи. Сохраняй посторонние staged и unstaged правки; в общих файлах изолируй свои изменения.
- В финальном ответе укажи хеш коммита и результат проверок. Если коммит не создан, явно сообщи причину.
- Выполняй push только по запросу пользователя.

## Проверки MetaRenderGraph

- Приёмка: короткий обычный smoke — запускается, GPU выполняет работу, результат есть, явных ошибок нет. Уже полученный результат не требует повторного запуска.
- После переноса работающего вычисления с DIRECT на COMPUTE повторно проверять математику не требуется.
- Проверки точности, граничных и искусственных ошибочных сценариев, матрицы режимов, длительные/повторные прогоны и профилирование выполнять только по отдельному явному запросу пользователя. Не создавать и не расширять тесты ради покрытия.
- При указании «только реализация» или запрете тестов/сборок проверять только код, ничего не запускать.
- При работе с этапами U1–U12 следовать [Verification Contract](docs/plans/2026-11-13-meta-render-graph/00-meta-plan.md#verification-contract); старые расширенные требования в отчётах не являются условиями приёмки.
