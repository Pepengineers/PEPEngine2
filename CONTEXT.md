# PEPEngine2

Термины загрузки сцены, игровой, бенчмарк-логики и рендера движка.

## Language

**Полная готовность Bistro**:
Состояние, в котором вся геометрия, материалы и текстуры Bistro готовы к отображению первого полноценного кадра. После этого сцена не требует фоновой догрузки.
_Avoid_: Первый кадр с частично загруженной сценой

**Бюджет загрузки Bistro**:
Оценочный предел временных данных одновременно подготавливаемых ресурсов сцены. Постоянные ресурсы готовой сцены и общий расход памяти приложения учитываются отдельно.
_Avoid_: Жёсткий предел всей RAM или VRAM

**Обновление системы**:
Полный проход одной ECS-системы по относящимся к ней данным текущего кадра. Следующая система начинает обработку после завершения всего прохода предыдущей.
_Avoid_: Одновременное обновление разных систем

**Пакет системы**:
Часть данных одного обновления системы, которую можно обработать независимо от других пакетов этой же системы. Совокупность пакетов покрывает все данные её прохода.
_Avoid_: Проход одной сущности через все системы

**Бенчмарк-объект Bistro**:
Существующая бутылка, стол или стул сцены Bistro, движущийся независимо от окружения для создания нагрузки. Все геометрические части одного предмета образуют один бенчмарк-объект.
_Avoid_: Дополнительная летающая копия предмета

**План обновления приложения**:
Заданный приложением порядок обновлений систем и собственных работ текущего кадра, включая зависимости между ними. В текущей модели этот порядок устанавливается вручную.
_Avoid_: Скрытый порядок обновления менеджера сцены

**Кандидат отрисовки**:
Экземпляр части меша, рассматриваемый рендером до отбора по видимости камеры или источника света. Один предмет Bistro может содержать несколько кандидатов с разными материалами.
_Avoid_: Только видимый объект

**ReadOnly CVar**:
Настройка приложения, которую можно установить на этапе запуска; после применения стартовой конфигурации доступно только чтение.
_Avoid_: Неизменяемая константа

**Default CVar**:
Настройка приложения, которую можно менять как на этапе запуска, так и во время работы.
_Avoid_: Только стартовая настройка
