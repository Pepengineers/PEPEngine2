# Bistro measurement traps verified in the November 2026 experiments

- Real rendered frames, GPU active intervals, and fixed physics ticks are different measures. Frame generation is not simulation throughput. CPU job-duration sums include scheduling and overlap; they are not additive frame costs.
- `App::UpdatePhysics` has a fixed-step loop and wall budget. Check the current source instead of assuming its values have stayed unchanged. Record requested time, executed ticks, accumulator continuity, active/total bodies, and wave phases. A faster renderer can execute more physics and hide some frame-time benefit.
- Pause must preserve debt and stop ticks. TimeScale changes requested time; an overloaded simulation may still lag. Compare equivalent simulated-time windows and seed; realtime soak remains a separate test.
- In November 2026, an independently authorized box-proxy change altered shapes, mass, and inertia during renderer work. Freeze the agreed physics inputs and keep its contribution separate. Source hashes and a uniquely named executable make this reviewable.
- Windows environment-presence checks can enable a flag whose value is empty. Delete disabled `PERF_JOLT`, `PERF_CONTROLS`, and other diagnostic flags explicitly. Verify observed controls, not just launcher intent.
- Read MSBuild tlogs only after the build finishes. If diagnostic linking is necessary, assert that the intended object replacement matches exactly once anywhere in the link response; the first object can be inline with flags. Preserve normal CRT/assertion/compiler settings. Keep these copies outside production source.
- For bounds or shadow-cache changes, reuse `RenderPipelineTests`, `ObjectDataJobsTests`, and `LightingGpuTests`. They cover conservative distant bounds, handle generation, direct edits, and cached/full-scan comparisons; inspect the relevant test before rederiving an already tested invariant.
- For Nsight, use the installed capture skill. Load a current tool schema, then print only needed fields. Native sampler startup failed on this machine in one run; CLI succeeded. One export used `BASE_UNLOCKED` while the wrapper expected `BASE`: verify the actual trace, warnings, frame count, and export paths before declaring success or failure. This is a known fallback, not permission to suppress other errors.
- Warm analytic-wind preparation may have a zero-duration GPU marker while grass expansion occurs in shadow views. Add a marker in a diagnostic copy when attribution is missing. Nested expansion timings already belong to parent pass totals.
