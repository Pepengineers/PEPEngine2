# Mighty Oak Trees by Jagobo

The oak geometry and textures are from [Mighty Oak Trees by Jagobo](https://sketchfab.com/3d-models/mighty-oak-trees-4f6ab5594a8a415aba3f958682b9ced5), licensed under [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).

Oak.fbx contains the first oak in the original Blender scene. Oak_High.fbx uses the same tree with simplified woody geometry and fewer whole foliage cards. The three PNG textures are original.
