# Bistro multi-GPU production validation

P6 exercises the production Bistro pipeline on an NVIDIA GeForce RTX 3060 Laptop GPU and AMD Radeon Graphics. The fixture loads the original Bistro render geometry, creates real grass, Water, Firefly and a skinned Fox, and renders both world posters and screen UI. The render-only fixture bypasses unrelated physics prop setup. The added point and spot lights are test inputs used to address real grass shadows. This report records correctness checks. Performance measurement is deferred.

The retained receipts, stdout, stderr and readbacks are in `Build/P6` in the validation worktree `D:/Project/PEPEngine2/.tmp/mgpu-feature-2026-11-08/integrator`. Each test receipt stores SHA-256 fingerprints before and after execution, including the executable, startup INI and relevant source. Each completed readback directory has its own SHA-256 manifest. Raw files and validation binaries are workspace artifacts. Evidence links point to that local worktree so they still identify the retained files when this report is read from the main checkout.

## Scope of the depth and HDR comparisons

The shadow transport compares actual secondary depth with the restored primary rectangles bitwise. Four Sun cascades cover 16,777,216 compared texels and the selected point light covers 393,216 across six faces. The separate frozen primary/secondary raster comparison checks the same caster geometry, current transforms, masked material inputs, current skin palettes and Sun matrices, then requires equal displayed Grass version, layout and packed field bytes. It requires identical coverage, mean absolute error at most 1e-5, at least 99.9% of covered texels within 1e-4, and zero errors above 1e-3 away from a same-cascade depth discontinuity. These bounds apply to this matched fixture.

In the frozen r22 diagnostic pair, depth coverage was identical across 13,318,770 occupied texels. Mean absolute error was 4.77214e-6 and p99.9 was approximately 6e-6. The maximum was 0.0738325. All 5,769 errors above 1e-3 had an adjacent depth discontinuity in their cascade. The images and per-pixel statistics remain available for independent review.
