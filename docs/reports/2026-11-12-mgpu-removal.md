# Удаление прежней MGPU-реализации

Решение пользователя 2026-11-12: удалить существующую систему MGPU целиком и подготовить отдельное задание на новый перенос только симуляции воды. Новая MGPU здесь не реализуется.

## Изменения

- Удалены старые CrossAdapter-маршруты всех техник, вторичные ресурсы приложения, MGPU runtime, snapshot protocol/transport, placed graph executor, legacy splits/replacements, shared-texture и shadow-depth transfers.
- Удалены связанные настройки, калибровка пересылок, поиск размещения/частот, проверки возраста и долга симуляции, отдельные MGPU-тесты и проекты.
- Сохранены обычный однокарточный граф, его async compute, основной renderer и однокарточные техники. Локальные облака Bistro подключены непосредственно через `GDX12CloudComponent`; старый путь cloud snapshots удалён.
- Сохранены текущая численная модель воды и оптимизации solver. Историческое имя численного режима `MGPUReference` заменено на `ReferenceModel`; это не новый режим расчёта. Удалены транспортные состояния и cadence/debt-обвязка.
- Обычный поиск пресетов сохранён вместе с проверками CPU и диагностикой отмены. Синхронизация перед изменением конфигурации и воспроизводимый seed применения результатов сохранены.
- ADR-0011/0012/0013 и старый MGPU quality-search план помечены отменёнными. Актуальный объём записан в [задании для Sol high](../plans/2026-11-12-water-only-mgpu-restart.md): перенос текущего solver, без требования воспроизводить физическую модель DX12.

## Проверки

- `App.vcxproj`, Debug x64, MSBuild 18 — успешная сборка с зависимостями.
- Успешно собраны Debug x64 проекты `RenderGraphTests`, `SecondGroupTests`, `FluidSortGpuTests`, `BistroRenderGraphTests`, `BistroStartupTests`, `ReflectionProbeTests`, `AOTests`, `LightingGpuTests`, `OffscreenUITests`, `WorldCanvasTests`.
- После восстановления локального подключения облаков повторно собраны App, BistroRenderGraphTests и BistroStartupTests.
- Выполнены CPU-тесты `BistroQualitySearchTests` и `ReflectionScheduleTests` — прошли.
- DXC: все 15 точек входа шейдеров воды и 6 точек входа симуляции частиц скомпилированы успешно.
- `python -B tools/tests/test_lighting_shaders.py` с Windows SDK DXC — 3 теста прошли.
- Исполняемые токены `FluidSolver.hlsl` совпадают с исходной версией до удаления; отличаются только комментарии.
- XML и перечисленные пути исходников проверены для всех 36 оставшихся проектов Apps/Engine. `git diff --check` проходит.
- Статическое ревью по шести направлениям завершено без открытых замечаний. Найденная потеря локального подключения облаков исправлена и перепроверена по исходникам. Большой diff проверялся выборочно; ревью не заменяет GPU-прогон.

В существующих локальных `Build/bin/**/Config/Engine.ini` удалены устаревшие MGPU-настройки; остальные значения сохранены. Исходные копии лежат рядом с суффиксом `.before-mgpu-removal`. Это игнорируемые артефакты сборки, не изменения конфигурации пользователя в коммите.

## Границы подтверждения

Приложение, GPU-тесты, визуальные проверки и замеры FPS в этой задаче не запускались. Успешная сборка GPU-тестов не означает успешный GPU-прогон. Добавленная проверка локальных облаков в BistroRenderGraphTests скомпилирована, но не выполнена на GPU.

Новая двухкарточная симуляция и обмен результатами остаются заданием следующего чата. Их корректность и ускорение не заявляются по результатам этого удаления.
