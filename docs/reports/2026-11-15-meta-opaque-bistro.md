# Bistro: базовый Opaque в MetaRenderGraph

Этап принят пользователем 2026-11-15. Обычный запуск App.MetaRenderGraph загружает исходные интерьер и экстерьер Bistro: GPU culling, depth prepass, GBuffer, PBR, исходные источники света, статический SkyBox/IBL и вывод HDR. Прозрачность, тени и остальные дополнительные техники выключены. Симуляция остановлена, камера свободная.

## Исправление подготовки кадров

Первоначальная версия читала write-combined upload-память для CPU-снимка сцены каждый кадр и записывала CopyBufferRegion отдельно для каждого элемента. Короткая PIX CPU capture по запросу пользователя обнаружила основную задержку главного потока в memcpy внутри SceneGeometry::Freeze, а рабочих потоков — в записи копирований SceneGeometry::Record.

- Для снимков используется существующее CPU-зеркало буферов. Материалы включают существующий TrackChanges.
- Ревизия и идентичность исходного ресурса определяют необходимость обновления. Неизменные данные сцены остаются в GPU-буфере каждого кадрового слота после его первичной загрузки.
- При реальном обновлении данные копируются непрерывными диапазонами существующих четырёх buckets, вместо команды на каждый элемент.
- Константы камеры/кадра, локальные источники и маски световой сетки читаются из существующих кадровых upload-ресурсов напрямую. Динамические константы и зависящая от камеры сетка продолжают обновляться на CPU.
- Удалены пустые диагностические операции из исполняемого кадра. Дополнительные UI-плакаты не создаются в Opaque-этапе.

Установившийся кадр содержит только reset visible counts, GPU scene culling, depth ExecuteIndirect, GBuffer ExecuteIndirect, initialize deferred HDR target, clustered deferred lighting, opaque HDR display transform и PRESENT handoff. Upload/copy/readback-пакетов в нём нет. Первичная загрузка ресурсов при запуске сохраняется.

## Проверки и короткие замеры

Release x64 собран успешно; короткий обычный запуск показал Bistro и GPU-работу без явных ошибок. Лог фиксирует ноль вызовов старого GDX12RenderGraph::Execute. Финальный исполняемый файл: `Build/bin/x64/Release/App.MetaRenderGraph/App.MetaRenderGraph.exe`.

RTX 3060 Laptop, основной адаптер 0, native 1280×800, начальная камера у входа. После появления FPS и короткого прогрева снимались показания раз в секунду. FPS — из заголовка окна, GPU — nvidia-smi, CPU — процессорное время процесса, выраженное в занятых ядрах.

| Версия | Отсчёты | Средний FPS | Средняя загрузка GPU | CPU, ядра |
|---|---:|---:|---:|---:|
| Исходный перенос | 8 | 45,21 | 34,38% | 1,37 |
| CPU-зеркало | 8 | 101,10 | 41,50% | 1,95 |
| Копирование диапазонами | 8 | 306,32 | 95,75% | 0,99 |
| Неизменные данные остаются на GPU | 12 | 356,21 | 97,25% | 0,70 |

Финальный диапазон: 354,36–357,61 FPS, GPU 93–98%. Автоматическая проверка сохранённого списка операций подтвердила отсутствие upload/copy/readback и выключенных техник; проверка сводки замера прошла. Сборка имеет прежние предупреждения о недостающих PDB библиотек.

Артефакты находятся локально в игнорируемом `Build/Verification/meta-opaque-perf`: `*-summary.json`, `*-samples.json`, `baseline-timing.wpix`, `resolved-stacks.json`, `resident-steady-operations.txt`, `resident-build.log`. Список проходов также сохраняется рядом с приложением в `Logs/opaque-steady-operations.txt`.

## Ограничения

Это короткие последовательные диагностические замеры одного ракурса, а не нормализованный аппаратный бенчмарк: частоты GPU различались между версиями. Между первым и вторым замером также убраны дополнительные плакаты. Отношение FPS описывает наблюдаемый результат всей системы, а не изолированный выигрыш одного изменения.

Расширенный `--smoke`, тестовые матрицы и длительные прогоны не запускались. Итоговое сравнение с App откладывается до конца переноса. Следующие техники не включены.
