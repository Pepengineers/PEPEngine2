# Адаптивное разрешение локальных теней Bistro

Черновик для согласования, 24 ноября 2026.

## Результат

Точечные источники и прожекторы получают карты разной детализации. Целевой диапазон по умолчанию — от 16×16 для мелкой области влияния на экране до 512×512 для крупной. Отражения читают результат выбора основной камеры. Захват кубической карты не запрашивает дополнительных граней и не повышает разрешение. Область изменений ограничена локальными тенями.

## Порядок реализации

1. **Выбор уровня.** Перед подготовкой локальных теней рассчитать приоритет каждого источника для основной камеры. Оценивать площадь влияния на видимые поверхности основной камеры, консервативно обрабатывать пересечение ближней плоскости и положение камеры внутри источника. Прожектору нужна одна грань, точечному источнику — шесть граней одного уровня. Для равных приоритетов использовать стабильный идентификатор. Сегодня оба вызова Freeze передают allReceivers=true. При переходе на отбор для камеры переиспользовать NeededFaces и проверку пересечения объёма света. Если область влияния не затрагивает основной вид, исключить источник из раскладки. Освещение источника сохраняется, захват отражения сам по себе не инициирует отрисовку тени.
2. **Размещение по бюджету.** Выделить локальным теням собственный бюджет внутри общего бюджета VRAM каждого GPU. Из одной раскладки получить адреса карт и их стоимость. Если запрошенные карты не помещаются, понижать разрешение или пропускать тени источников меньшего экранного приоритета. Предлагаемый вариант — массивы глубины по каждому используемому размеру. Поддержать уровни 16, 32, 64, 128, 256 и 512. Существующие явно заданные разрешения 384 и 1024 требуют согласованной трактовки в настройках, сохранённых профилях и поиске. Нулевое значение сохраняет выключенные тени. Получать физический размер массива через D3D12. Включать в бюджет статическую и итоговую глубину, слоты кадров, ресурсы на каждом задействованном GPU и пик при замене.
3. **Отрисовка и чтение.** Заменить единственный размер и адрес первой грани на выбор массива и диапазона слоёв. Одна раскладка определяет DSV, viewport, scissor, копирование статической глубины и шаг фильтрации PCF. Передать те же адреса в deferred lighting, прозрачность и reflection capture. Статический захват сохраняет свою семантику статической глубины при той же раскладке. Отсутствие готовой карты влияет только на теневой множитель.
4. **Смена уровня без скачка работы.** Ввести разные пороги повышения и понижения, сохранять назначение неподвижного источника между кадрами. Ограничивать работу на переходы по стоимости обновляемых граней. Публиковать новое поколение карты вместе с адресом после подготовки, старое освобождать после завершения всех читающих GPU-команд. Учесть резкую смену камеры, устаревшую карту движущегося фонаря и одновременные запросы нескольких кадров.
5. **Второй GPU и подбор качества.** Передавать фактические размеры граней и поколение размещения через Exact/Latest. Удалённая проба сегодня использует ShadowFallback. Для неё импортировать опубликованные карты основной камеры по мере необходимости и учитывать стоимость копий. Проверять бюджет каждого владельца до аллокации. Использовать одну оценку в настройках, старте и поиске. Сохранять в результатах запрошенный потолок, действующее распределение и причину отказа. Сравнение кандидатов должно использовать воспроизводимое начальное состояние раскладки.
6. **Приёмка.** Собрать Release и сделать короткий проход по Bistro с приближением к фонарю и разворотом камеры. Проверить, что размер реальной текстуры соответствует уровню, источник за границей экрана сохраняет тень на видимой стене, отражение использует расположение граней основной камеры, смена уровня не читает чужую грань. Зафиксировать распределение уровней и размер выделенных атласов. Доказательство улучшения времени кадра потребует отдельного парного замера того же маршрута.

## Решения первого раунда

Согласованы экранная площадь влияния, отсутствие карты для источника без вклада в основной вид и отдельный бюджет локальных теней с понижением или пропуском при переполнении. Один фонарь вне кадра, освещающий видимую стену, и фонарь, влияющий только на отражение, дают разные результаты: первый участвует в распределении, второй пропускается.
