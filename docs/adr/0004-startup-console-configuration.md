# Стартовые CVar применяются до инициализации приложения

Конструктор ядра загружает INI до создания членов приложения, окна и модулей. `ReadOnly` допускает запись только на этом этапе, затем закрывается для записи; `Default` допускает изменения и во время работы. Так настройки, определяющие размер GPU-ресурсов, не расходятся с уже созданными ресурсами.

При отсутствии `Config/Engine.ini` рядом с exe сохраняются значения из C++. Первая синтаксическая ошибка, неизвестное имя, недопустимое значение или ошибка чтения записывается в `Logs/Engine.log` рядом с exe и прерывает запуск. Парсер прекращает обработку на первой ошибке; частично применённая конфигурация не используется работающим приложением. Синтаксис INI разбирает закреплённый submodule inih; собственного парсера INI нет.
