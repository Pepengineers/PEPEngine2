# Отдельные компоненты SkyAtmosphere и SkyBox

Процедурную атмосферу оформляем отдельным компонентом SkyAtmosphere, а существующее небо из изображения окружения — отдельным SkyBox. Пользователь выбрал явное разделение компонентов сцены и один активный источник одновременно для неба и IBL: совместный режим HDRI-фона с атмосферной перспективой в этот этап не входит. Выбор и отключение источника должны быть явными, а не зависеть от порядка обхода компонентов.
