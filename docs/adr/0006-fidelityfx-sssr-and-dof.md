# FidelityFX как донор SSR и DOF

Для SSR используем готовые FidelityFX SSSR с Reflections Denoiser, для глубины резкости — FidelityFX DoF; базовая исследованная версия — SDK v1.1.4. Пользователь выбрал выделенные компоненты с DX12 backend вместо собственной реализации этих алгоритмов по статьям: это позволяет опираться на проверяемые контракты готового кода, сосредоточившись на интеграции с PBR, HDR, отражениями и историей кадров PEPEngine2. Демонстрационный фреймворк Cauldron не переносим; motion blur остаётся отдельной реализацией по Guertin/McGuire/Nowrouzezahrai, HPG 2014.
