# Полноценные алгоритмы рендера вместо буквального переноса MGPU-демо

Техники из Multi-GPU-Render-DX12 переносим с исправлениями и необходимой интеграцией в текущий PBR/HDR-рендер; для неполных или проблемных реализаций выбираем алгоритмы по первичным статьям и проверяемым реализациям, а не сохраняем старую картинку как эталон правильности. Сначала добавляем отсутствующую базу рендера (три переключаемых AO, SSR, два режима cubemap-отражений, DOF и motion blur), затем согласованные дополнительные подсистемы. Весь этот этап выполняется на одном GPU: межадаптерное распределение, копирование и синхронизация отложены, чтобы отдельно проверить качество и стоимость самих техник.
