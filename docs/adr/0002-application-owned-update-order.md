# Приложение явно задаёт порядок систем и jobs

Порядок обновлений и зависимости между системами задаёт приложение в своём Tick/Update. Здесь же оно вставляет собственные Job и ParallelJob; менеджер сцены не создаёт скрытую цепочку и не запускает те же системы повторно. Это даёт приложению прямой контроль над составом нагрузки и точками синхронизации, в отличие от автоматической цепочки по приоритетам внутри SceneManager.

Объекты асинхронных работ сохраняются до Complete и не изменяются во время выполнения. Автоматическую сортировку по метаданным по образцу Unity откладываем; текущая версия использует явно переданные JobHandle.
