# Независимые SR и FG при SDR Reinhard output

Пользователь выбрал независимый выбор апскейлера и генератора кадров с проверкой совместимости. Последним уточнением от 2026-11-01 HDR-вывод и ACES исключены: сохраняются существующие Reinhard → sRGB и SDR swapchain. Внутренний scene-linear HDR проходит через SR до тонмаппинга; FG работает с финальным display-color после тонмаппинга через presentation integration. Runtime пересоздание допускает короткое ожидание GPU; при недоступном SR применяется native, при недоступном FG — Off, с явной причиной fallback.

Решение согласовано 2026-11-01, реализовано 2026-11-02; фактические проверки и аппаратные ограничения: [отчёт](../reports/2026-11-02-runtime-reconstruction.md). Объём и приёмка: [задача](../tasks/render-output-reconstruction.md). Альтернатива — жёсткие SR/FG пары одного производителя — отвергнута ради независимого выбора; совместимость при этом нельзя обещать для произвольной пары SDK/железа.
