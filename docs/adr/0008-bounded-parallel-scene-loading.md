# Параллельная подготовка ресурсов с ограниченным бюджетом памяти

Дополнение 2026-11-01: после сообщения о многоминутном запуске из Rider и переполнении
памяти ограничение на постоянный кэш ниже заменено пересоздаваемым кэшем производных
данных `Build/AssetCache`. Исходники остаются источником истины; изменение размера или
времени записи OBJ/MTL/текстуры и версии/параметров импортера меняет ключ. Подробности
исправления и условия замеров: [отчёт](../reports/2026-11-01-rider-startup.md).

Следующее уточнение того же дня: по запросу пользователя геометрия сохраняется уже
в формате `Mesh` движка (`.pepmesh`), включая материалы и данные скиннинга. Повторное
чтение не создаёт Assimp::Importer; Assimp используется только при отсутствии или
невалидности кэша. Формат версионирован, целостность проверяется SHA-256, публикация
файла атомарная. Применяется к существующему пути загрузки OBJ/Bistro.

Пользователь подтвердил загрузку полностью готовой Bistro до первого кадра, сохранение импорта исходных моделей через Assimp и минимальную конфигурацию с 16 ГБ RAM. Запекание ресурсов отложено до редактора. Независимые импорты и декодирование текстур выполняются через принадлежащий приложению общий JobSystem; регистрация ресурсов, создание материалов, изменение ECS и запись GPU-команд остаются в потоке-владельце. Это позволяет использовать существующие реестры без глобальных блокировок и отдельного загрузочного пула.

`Loading.TransientBudgetMiB` задаёт оценочный бюджет временных данных, по умолчанию 1024 МиБ. Он считывается один раз перед загрузкой, ограничивает одновременно выполняемые работы и пакеты GPU-upload, но не является пределом всей RAM или VRAM: внутренние аллокации импортера/декодера и постоянные CPU-кэши требуют отдельного измерения. Ресурс крупнее бюджета выполняется отдельно с диагностикой превышения. Изменение CVar применяется при следующей загрузке.

GPU-upload объединяется в command lists, а исходные upload-буферы и ресурсы сохраняются до завершения fence. Открытый, ещё не отправленный command list нельзя возвращать в свободный пул. Удаление ожидания после каждой текстуры без этих правил было отвергнуто, поскольку нарушало бы время жизни ресурсов.
